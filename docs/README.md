# ReliefOS Documentation Set

This directory contains the consolidated v2.0 project documentation.

1. `prd.md` — WHAT / WHY
2. `trd.md` — TECHNICAL REQUIREMENTS
3. `architecture.md` — HOW THE SYSTEM IS STRUCTURED
4. `rules.md` — CONSTRAINTS / INVARIANTS / BEHAVIOR
5. `design.md` — UX/UI

7. `memory.md` — DURABLE PROJECT CONTEXT

## Source basis

The documents combine:
- the official ELEVATE EL-02 problem statement already provided to the project,
- the team's previously locked decisions,
- the uploaded `ReliefOS_PRD_v1.0.pdf`.

The supplied ReliefOS PRD is treated as a strong design/reference document, while its solution-specific additions are explicitly distinguished from official problem requirements.
